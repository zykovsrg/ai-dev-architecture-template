# Связи архитектуры: границы и проверки

Дата: 2026-09-09. Это перечень подтверждённых в просмотренных центральных процедурах связей, а не список всех сервисов приложений или всех установленных плагинов. Наличие инструмента в интерфейсе не доказывает его использование архитектурой.

| Связь | Основание | Что проверено / следующий безопасный шаг |
| --- | --- | --- |
| Apple Calendar | `ai/architecture.md`, раздел Guarded Apple Calendar; `ai/skills/hub-calendar/SKILL.md`; `calendar-policy/` проекта архитектуры | В предыдущем аудите прошли локальные тесты политики и сборка моста. Живой доступ не проверен. Проверить доступность защищённого инструмента и чтение разрешённого календаря за небольшой выбранный интервал; запись только с отдельным preview. |
| Obsidian | `ai/architecture.md`, раздел Central Obsidian Projection; генератор и обратная синхронизация | Локальные тесты прошли, но A02/A03/A13 показывают ошибки стыков. После исправления — вымышленная задача во временном хранилище и сверка кругового переноса. Это локальная связь, не облачный сервис. |
| Rolling Audio Recorder | `ai/skills/hub-workflows/SKILL.md`; `scripts/assistant-workflows.sh` проекта архитектуры | Контракт export/status и проверки адаптера рассмотрены. Живой экспорт не запускался: это операция с личным аудио, а не безвредный тест доступности. Для живой проверки пользователь выбирает период; сам диктофон как приложение вне аудита. |
| Git / GitHub | `ai/skills/hub-project-create/SKILL.md`, этап создания приватного репозитория; `ai/architecture.md` | Локальная установка проверялась в изоляции. Реальный push/create не проверялся. Достаточно сначала проверить доступность клиента и чтение одного согласованного репозитория; это не докажет право на запись. Не создавать репозиторий ради диагностики. |
| Codex / Claude как среда выполнения | Входные инструкции, установщики, существующий аудит сессий | Требуется пилот открытия проекта после удаления копий правил. История диалогов — ограниченная самопроверка, не массовое чтение архива. |
| Расписание самоаудита Codex | Уточнение пользователя; исторический runbook аудита | Вывести из эксплуатации при рефакторинге. Текущее состояние запуска не проверено; сейчас не отключено. Не заменять автоматически другой фоновой службой. |

Google Drive/Docs/Sheets доступны как инструменты среды, но обязательная центральная связь с Google не обнаружена в просмотренных `ai/architecture.md` и общих процедурах `ai/skills/`. Сервисы отдельных прикладных проектов не включены в проверку работоспособности приложений. Известный вопрос о сервисном ключе Google (A18) остаётся отдельным уведомлением о риске; содержимое ключа не читалось.

Итого: четыре явных рабочих стыка для отдельной приёмки — календарь, Obsidian, диктофон и GitHub; дополнительно совместимость двух сред и вывод старого расписания. Перечень достаточно небольшой для поочерёдной проверки. Утверждать, что это все внешние сервисы всех 57 приложений, нельзя и не требуется новым объёмом аудита.

Следующая проверка должна отделять три результата: «инструмент доступен», «чтение работает», «подтверждённая запись работает». Ни один не подменяет другой. Этот документ не утверждает, что живые проверки уже выполнены.
