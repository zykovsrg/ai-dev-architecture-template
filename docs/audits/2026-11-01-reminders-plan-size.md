# Большие планы синхронизации «Напоминаний»

Подтверждённый отказ: план версии 2 размером 2144056 байт при физическом лимите 2097152. Устранение повторной конфигурации уже было установлено; остаточная причина — полный объём конфигурации, двух точных проекций задач и снимка приложения.

Большие планы теперь используют версию 3: конфигурация и проекции задач сжимаются без потерь. Сохраняются физический предел 2 МиБ, контрольная сумма до распаковки, точный CAS, полный снимок, версии, неизменяемый план, атомарная публикация, квитанции и возобновление. Объём распаковки ограничен 16 МиБ; незавершённые потоки и дополнительные данные отвергаются. Малые планы остаются версией 2, чтение версий 1 и 2 сохранено.

Проверки: 120 тестов внешней отмены, 65 тестов принятой политики приложения; восемь мутаций с поведенческими отказами и успешным повтором. Независимая приёмка кода и тестов: принято. Точный публикационный набор на свежей удалённой главной ветке прошёл 120 тестов; независимый проверяющий отдельно выполнил три ключевые проверки.

Три тестовых файла включены в связанный набор: базовые синтетические фикстуры, проверки версии 2 и новые проверки больших планов. В опубликованной главной ветке их раньше не было. Личные данные приложения в публикацию не входят.

Штатная установка заменила только scripts/reminders_external_retirement.py. Дополнительный этап установки календарного компонента успешно завершён после запуска с необходимым доступом; календарь не выбран, событий не меняли.

Реальный общий sync --apply создал план версии 3 размером 781314 байт. Операция отмены четырёх отсутствующих UUID завершилась phase=complete. Контрольное чтение канонических записей подтвердило dropped и точную квитанцию для всех четырёх. Результат общего запуска будет добавлен после завершения.

Рабочие репозитории содержат прежние изменения. Для отправки используется новая ветка от свежего origin/main с отдельным временным индексом и явным набором путей. HEAD, обычный индекс и прежняя работа не переключаются и не сохраняются вместе с исправлением. Принятый независимым проверяющим набор кода: один исполнитель и три тестовых файла.
