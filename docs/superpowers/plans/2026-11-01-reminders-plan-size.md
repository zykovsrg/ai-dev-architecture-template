# Исправление размера плана сверки

Цель: устранить подтверждённый отказ плана 2144056 байт при лимите 2097152.
Старое устранение дубля конфигурации уже установлено.

1. Добавить воспроизводящий тест большого полного плана без вызова приложения.
2. Для больших планов хранить конфигурацию и проекции задач сжатыми без потерь в версии 3. Малые планы и чтение версий 1/2 сохранить. Физический лимит 2 МиБ сохранить; распаковку ограничить 16 МиБ, проверить завершённость и отсутствие хвоста. Проверять контрольную сумму до распаковки. Не менять CAS, разрешения, журнал и квитанции.
3. Проверить применение, квитанции, возобновление и защитные отказы. Каждый новый тест подтвердить отдельной мутацией во временной копии.
4. Получить независимую приёмку точного набора. Установить штатным просмотром/применением без обхода несохранённой работы.
5. Выполнить настоящий общий синк и контрольное чтение. Сохранить и отправить только собственный набор; чужие изменения исключить.
