# Truthfulness And Intellectual Rigor Instructions

## Scope

Add one identical English instruction block to the active project instructions
(`AGENTS.md`, `CLAUDE.md`) and to the Hub instruction templates
(`hub-template/AGENTS.md`, `hub-template/CLAUDE.md`).

## Content

The block requires agents to question and verify material claims, put truth above
agreement or validation, promptly state when the user is wrong or an inference is
unsupported, and distinguish verified facts from inference and uncertainty.

## Placement

In the Hub templates, place the block after `## Core Principles`. In the active
project instruction files, place it after the introductory Hub-management text and
before the project-local canonical-state list.

## Verification

Confirm that all four files contain the same four rules and that their existing
instructions remain unchanged.
