# Стартовые промты

Работа начинается через Personal AI Hub. Общие правила и workflows не устанавливаются внутрь проекта.

## Новый проект

```text
Создай новый проект через Personal AI Hub. Покажи точный proposed path, scaffold, registry/card changes и дождись моего подтверждения до записи. После создания проверь Hub registry и только затем предложи поставить первую задачу.
```

## Существующий проект

```text
Подключи этот проект к Personal AI Hub. Если он ещё не зарегистрирован или находится вне разрешённого Hub root, используй безопасный register/migrate workflow: сначала inventory и preview, затем отдельное подтверждение на перемещение/регистрацию. Сохрани project memory и knowledge; не восстанавливай старые shared rule copies внутри проекта.
```

## Переключение в проект

```text
Переключись на нужный зарегистрированный проект через Hub. До явного подтверждения покажи project ID и exact registered path и не читай project code, memory или knowledge за пределами разрешённого routing scope.
```

## Общий вопрос по задачам

```text
Покажи актуальные задачи всех активных зарегистрированных проектов через personal-assistant scope. Для discovery сначала используй compact task index; канонические task files открывай только для выбранных записей, если нужной детали нет в индексе. В фактическом ответе ссылайся на canonical source paths.
```

## Knowledge

Knowledge включается только по необходимости через `hub-knowledge-enable`. Для сохранения подтверждённого повторно используемого материала используйте `hub-knowledge-capture`; для проверки актуальности — `hub-knowledge-review`. Knowledge не является обязательным контекстом каждой сессии.
