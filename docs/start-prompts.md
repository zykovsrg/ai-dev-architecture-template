# Стартовые промты

Работа начинается через Personal AI Hub. Общие правила и workflows не устанавливаются внутрь проекта.

## Новый проект

```text
Создай новый проект через Personal AI Hub. Покажи точный путь, заготовку файлов, изменения реестра и карточки и дождись моего подтверждения до записи. После создания проверь реестр Hub и только затем предложи поставить первую задачу.
```

## Существующий проект

```text
Подключи этот проект к Personal AI Hub. Если он ещё не зарегистрирован или лежит вне `_ai-hub/projects`, используй безопасный register/migrate workflow: сначала список и preview, затем отдельное подтверждение на перенос и регистрацию. Сохрани память проекта и knowledge; не восстанавливай старые копии общих правил внутри проекта.
```

## Переключение в проект

```text
Переключись на нужный зарегистрированный проект через Hub. До явного подтверждения покажи project ID и точный путь из реестра и не читай код, память или knowledge проекта.
```

## Общий вопрос по задачам

```text
Покажи актуальные задачи всех активных зарегистрированных проектов. Для поиска сначала используй compact task index; канонические файлы задач открывай только для выбранных записей, если нужной детали нет в индексе. В ответе ссылайся на канонические пути.
```

## Knowledge

Нужен модуль `knowledge` (см. [README](../README.md#модули)). В существующем проекте knowledge включается через `hub-knowledge-enable`. Сохранить материал — `hub-knowledge-capture`, проверить актуальность — `hub-knowledge-review`. Knowledge не читается в каждой сессии, только по запросу.
