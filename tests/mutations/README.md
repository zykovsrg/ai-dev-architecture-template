# Постоянный каталог

`catalog.json` описывает намеренные ошибки и точные тесты, которые должны их обнаружить.
Общий запуск: `bash scripts/architecture-test.sh --mutation`.

При добавлении теста:

1. Добавьте настоящее утверждение и независимую подготовку входа.
2. Добавьте содержательную подмену проверяемого поведения в `mutations`.
3. Укажите полный фактический ID в `expected_ids` и его настоящий файл в `expected_sources`.
4. Для параметров укажите каждый ID отдельно. Для подслучаев используйте ID родительского метода.
5. Убедитесь, что исходный тест проходит, подмена вызывает его собственный отказ, а восстановленный тест проходит.
6. Выполните полный запуск и сохраните отчёт. Новый метод или файл без подтверждения должен дать отказ.

Обычные наборы собирают `test_*.py`. Календарные тесты собирает «Пайтест», включая `*_test.py`.
Сценарии оболочки объявляют собственные ID через `tests/helpers/shell-scenarios.sh`.
Внешние команды и чтение результатов утверждений выполняйте через `scenario_exec` в родительской оболочке.
Не помещайте `scenario_exec` в подстановку команды. Перед сравнением проверяйте исход команды и полный ожидаемый диагностический вывод.

Подмены кода задают точный `source`, `symbol`, `before`, `after`.
Для оболочки используется `@shell`, для разрешённых документов — `@document`.
Файловые операции разрешены только существующим узким перечнем помощника.
Поля `expected_sources` и `provenance` проверяет внешний общий запуск; в строгий инструмент передаётся закреплённая предметная проекция.

Самопроверки инструментов используют только явные пары `subject_tools` и внешний неизменяемый наблюдатель.
Они не разрешают менять сам тест, его помощников или исполняемый наблюдатель.
Пути инструментов и их байты закрепляются в `driver_sha256` и соответствующих полях строгого каталога.
При изменении инструмента обновите закрепление после проверки новых байтов; старый отчёт не подтверждает новую версию.

Исторический `tests/mutation-cases.json` сохраняется отдельно. Его выбранный набор не заменяет полный каталог.
Каталог подтверждает все объявленные тесты; он не обещает обнаружить любую возможную ошибку программы.
