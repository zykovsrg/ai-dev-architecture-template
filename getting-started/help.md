# Помощь

Hub помогает вести задачи и не терять контекст проекта. Вы пишете обычным
языком. Агент сам выбирает нужный порядок действий.

## Полезные фразы

| Напишите агенту | Что будет |
| --- | --- |
| `Открой проект <название>` | Выберет проект и попросит подтвердить путь. |
| `Поставь задачу: <текст>` | Запишет текущую задачу после проверки. |
| `Покажи будущие задачи` | Покажет идеи и задачи на потом. |
| `Поставь текущую задачу на паузу` | Сохранит её, чтобы вернуться позже. |
| `Заверши задачу` | Проверит результат, закроет задачу и сохранит его в Git проекта. |
| `Покажи, что горит` | Покажет просроченные и заблокированные задачи всех активных проектов. |
| `Вот расшифровка встречи: <текст>` | Разложит задания по проектам и покажет предложения. |
| `Создай проект <название>` | Сначала покажет будущий проект и спросит разрешение. |

Эти фразы работают, только если включён нужный модуль:

| Напишите агенту | Модуль |
| --- | --- |
| `План на сегодня`, `Вечерний обзор`, `Недельный обзор` | planning |
| `Что у меня в календаре завтра?` | calendar |
| `Сколько сделано по цели?` | goals |
| `Сохрани это в knowledge` | knowledge |
| `Внеси изменения из Obsidian` | obsidian |

Какие модули стоят в Hub, записано в `ai/modules.md`. Если модуля нет, агент
так и скажет. Как включить модуль: `docs/update.md`, раздел «Модули».

## Подтверждение

Агент сначала показывает важные изменения, затем ждёт вашего подтверждения.
Это относится к задачам, календарю, Obsidian, новым проектам, правилам
архитектуры, переносу файлов и удалению. Проверка и предложение ничего не
меняют.

## Obsidian

В Obsidian есть общий обзор проектов и отдельная доска у каждого проекта.
Доску можно править вручную. Агент не переносит такие правки сразу: сначала
проверяет их, показывает список изменений и ждёт подтверждения. Если проверка
остановилась, агент покажет причину и ничего не испортит.

## Встречи

Расшифровку встречи агент разбирает по проектам и показывает один пакет
предложений. Перед подтверждением можно убрать отдельные пункты. Новый проект
тоже создаётся только после подтверждения.

## Удаление

Удаление — отдельная операция: `docs/uninstall.md`. Выключить один модуль —
`docs/update.md`, раздел «Модули».
