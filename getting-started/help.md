# Помощь

Архитектура помогает вести задачи и не терять контекст проекта. Вы пишете
обычным языком. Агент сам выбирает нужный порядок действий.

## Что можно сделать

- Открыть или выбрать проект.
- Поставить, поставить на паузу или закрыть задачу.
- Посмотреть все проекты и их текущие задачи.
- Открыть доску одного проекта в Obsidian.
- Передать заметки или расшифровку встречи.
- Создать новый проект.
- Обновить правила архитектуры.

## Полезные фразы

| Напишите агенту | Что будет |
| --- | --- |
| `Помощь` | Коротко расскажет, что можно сделать. |
| `Открой проект <название>` | Выберет проект и попросит подтвердить путь. |
| `Поставь задачу: <текст>` | Запишет текущую задачу после проверки. |
| `Покажи будущие задачи` | Покажет идеи и задачи на потом. |
| `Поставь текущую задачу на паузу` | Сохранит её, чтобы вернуться позже. |
| `Заверши задачу` | Проверит результат и попросит подтверждение закрытия. |
| `Покажи обзор проектов` | Откроет список проектов и их текущих задач. |
| `Открой доску <проекта>` | Откроет Kanban-доску одного проекта. |
| `Внеси изменения из Obsidian` | Проверит правки на доске и покажет предложение. |
| `Вот расшифровка встречи: <текст>` | Разложит задания по проектам. |
| `Создай проект <название>` | Сначала покажет будущий проект и спросит разрешение. |
| `Проверь обновления архитектуры` | Покажет, есть ли новая версия. |

## Obsidian

В Obsidian есть общий обзор проектов и отдельная доска у каждого проекта.
Можно править доску вручную. Агент не переносит такие правки сразу: сначала
проверяет их, показывает список изменений и ждёт подтверждения.

Если проверка остановилась, это значит, что карточка не совпадает с задачей
или в ней есть непонятное поле. Агент покажет причину. Он не испортит файлы
проекта автоматически.

## Встречи

Можно прислать расшифровку встречи. Агент найдёт задания, сгруппирует их по
проектам и покажет, куда предлагает их записать. Для каждого проекта нужно
отдельное подтверждение. Новый проект тоже сначала создаётся только после
подтверждения.

## Подтверждение

Агент сначала показывает важные изменения, затем ждёт вашего `подтверждаю`.
Это относится к задачам, Obsidian, новым проектам, правилам архитектуры,
переносу файлов и удалению. Проверка и предложение ничего не меняют.

## Если нужна помощь

Напишите `Помощь`, `что умеешь` или `как работать`. Старый запрос
`покажи стартовый экран` тоже работает.

## Удаление архитектуры

Удаление — отдельная операция. Напишите `Помоги удалить архитектуру`.
Сначала агент покажет затронутые файлы и спросит, что сохранить.
