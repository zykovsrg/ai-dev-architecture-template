# Нативное чтение истории «Напоминаний»

Исходники восстановлены 30 октября 2026 года с прямого разрешения пользователя
из удалённой экспериментальной копии `reminders-connection-20261024/xiaofeng-han-apple-reminders-mcp-8038474`.
Восстановлены только Package.swift, Sources, Tests, Resources и scripts.
Базовый upstream: 8038474aeb24bae7816ffd9570abc1606667e99d; восстановленная копия
также содержит местные изменения Хаба, поэтому не равна чистому upstream.

Исправление в HubCancellationPlan.swift разрешает чтение завершённых отмен
после подтверждённой цепочки расширений разрешённых списков. Каждый переход
проверяет точные байты, подтверждение, завершение, идентичность операции и Хаба.
Удаление, восстановление и незавершённые операции сохраняют точную проверку суммы.

Установка использует отдельный `cancellation_status_binary` исключительно
для `hub_cancel_status` версии 2 с назначением `task_cancellation`.
Остальные операции используют прежний `cancellation_binary`: его контрольная
сумма привязана к доказательствам безопасного восстановления.
Не заменять его этой сборкой без повторной проверки соответствующих гарантий.

Сборка: `swift build -c release --product AppleRemindersMCP`.
Проверка чистого валидатора без доступа к приложению:
`python3 -m unittest discover -s modules/planning/tests -p test_reminders_permission_native.py`.
Для проверки реального чтения нужен стандартный доступ macOS к «Напоминаниям».
Не менять системные разрешения и подписи существующих программ автоматически.

Результаты исправления и контрольные суммы:
`docs/audits/permission-expansion-2026-10-30/`.
