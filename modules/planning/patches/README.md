# Явный признак общего доступа

Патч `native-reminders-explicit-sharing.patch` сохраняет булево поле `shared` для обоих значений: `false` и `true`. Поле `people` выводится только для общего списка. Защитные проверки привязки остаются прежними.

Исходная программа: «Apple Reminders MCP», базовое сохранение upstream `8038474aeb24bae7816ffd9570abc1606667e99d`. Проверенная локальная версия дополнительно содержит изменения Хаба. Патч рассчитан на версию с показанным контекстом; он не является полной копией программы.

В отдельной копии исходников программы сначала проверьте применение:

```sh
patch --dry-run -p1 < /path/to/native-reminders-explicit-sharing.patch
patch -p1 < /path/to/native-reminders-explicit-sharing.patch
swift test
```

Тест `ListSharingTests.explicitSharingState` проверяет оба значения `shared` и наличие `people`. Если удалить запись `shared` в `Output.list`, тест должен завершиться ошибкой. После восстановления записи тест должен пройти.

Патч не меняет установленные программы, разрешения системы, подписи, разрешённые списки, журналы операций или проверки идентичности. Сборка и тесты не заменяют отдельную проверку установки.
