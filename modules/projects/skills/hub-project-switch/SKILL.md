# Переключение проекта

Используйте навык, только когда пользователь просит перейти из подтверждённого
проекта в другой. Переключение проекта не является переключением задачи. Оно
не должно менять текущую задачу, приостанавливать или заменять её либо редактировать память задач любого проекта.

Правила модуля: `ai/rules/projects.md`.

## Порядок действий

1. Используйте `hub-project-router`: выберите наиболее вероятный зарегистрированный
   проект, проверьте его точный путь и сразу перейдите без отдельного подтверждения.
   Архивные проекты исключайте без отдельного запроса пользователя.
2. `hub-project-router` сам записывает выбор, сообщает переход и выполняет
   `hub-environment-check`. Используйте его результат без повторения этих шагов.
   При отказе выбора или проверки среды остановитесь; запись активного проекта
   не заменяет проверку доступа. Дальнейшую работу передайте нужному процессу Хаба.
   Не меняйте задачу прежнего проекта и не читайте его неизвестное состояние.
   Не требуйте дубликаты общих инструкций в проекте.

При равновероятных вариантах задайте один вопрос о проекте через `hub-project-router`.
Если пользователь просит перенести работу между проектами, сначала определите
область и очищенный план передачи. Сам переход не разрешает копирование памяти.
